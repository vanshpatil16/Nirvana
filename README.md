# Bhumi Niti Dashboard

Build the FIRST production-quality route of my web application: the BHUMI-NITI Dashboard. BHUMI-NITI (भूमि-नीति) is a National Digital Platform for Evidence-Based Land Governance. It brings land data, GIS intelligence, research, policy analysis, disputes, climate risk and innovation into one platform. IMPORTANT: I have attached a reference screenshot for the visual direction. Use it as inspiration/reference for composition, hierarchy, spacing and overall feel, but DO NOT simply copy it pixel-for-pixel. The goal is a premium Indian government/research platform UI that could realistically be presented at Smart India Hackathon. DESIGN PHILOSOPHY ----------------- The UI must feel: - Clean - Premium - Trustworthy - Government-grade - Research-oriented - Modern but NOT "AI slop" - Data-rich but NOT cluttered - Extremely readable - Light theme - Calm earth/land-inspired colours - Strong visual hierarchy - Professional enough for policymakers and researchers DO NOT use: - Dark blue SaaS dashboards - Cyberpunk aesthetics - Excessive gradients - Neon colours - Glowing AI effects - Excessive glassmorphism - Huge amounts of text - Random decorative cards - Fake 3D illustrations everywhere - Generic AI chatbot styling Use whitespace aggressively. COLOR SYSTEM ------------ Primary: - Deep forest green - Muted emerald - Warm ivory / off-white - Soft sage - Earth brown - Muted terracotta - Small amounts of saffron/orange for warnings - Small amounts of blue for informational states Background: Warm ivory / extremely light neutral. Cards: White with extremely subtle borders and shadows. Typography: Use a refined modern sans-serif for UI. Headings can use a sophisticated serif or high-quality display font sparingly. The overall visual identity should communicate: LAND + DATA + POLICY + INDIA LAYOUT ------ Create a responsive desktop-first dashboard. LEFT SIDEBAR ------------ Fixed vertical sidebar approximately 240px wide. Top: BHUMI-NITI logo भू-नीति Subtitle: National Platform for Research & Policy Innovation in Land Governance Navigation: 1. Dashboard 2. GIS Explorer 3. Record vs Reality 4. Disputes & Conflicts 5. Policy Lab 6. Research Hub 7. AI Research Copilot 8. Innovation Portal 9. Collaborative Workspaces 10. Data & APIs 11. Impact & Monitoring Dashboard must be highlighted with a soft green background and a thin green indicator. Use clean line icons. Bottom of sidebar: Small India/government visual identity area. Text: People. Land. Policy. A Better Bharat. Do not make this area too large. TOP HEADER ---------- Main content starts to the right of sidebar. Top horizontal header: LEFT: Global search input. Placeholder: "Search villages, districts, policies, research papers, datasets..." Search should have: - Search icon - Keyboard shortcut hint "Ctrl K" RIGHT: - Theme/light mode icon - Language selector: EN - Notification icon - User avatar - User name - Role: Researcher - Dropdown HERO SECTION ------------ Create a wide, elegant hero banner. Left side: Small eyebrow: NATIONAL LAND INTELLIGENCE Large headline: "Data. People. Policy. A Stronger Tomorrow." Supporting text: "Integrated knowledge, real-world evidence and collaborative innovation for sustainable land governance." Buttons: "Explore the Map →" Secondary: "View Research" RIGHT SIDE: Use a beautiful wide Indian landscape / land-use visual. The image should feel like: - Indian agricultural landscape - river - settlement - forest - infrastructure - subtle topographic/map elements Do NOT make the image overly cinematic. Add a small quote card: "Land is not just a resource, it is a foundation for people, prosperity and the planet." RIGHT SIDE should contain compact intelligence panels. SECTION TABS ------------ Above the main content: India's Land in Perspective Tabs: - Land Use Change - Disputes - Climate Risk - Socio-Economic Right: "View Full Screen →" MAIN INDIA GIS MAP ------------------ This is the most important visual element on the dashboard. Create a large India map panel. Use MapLibre GL / Mapbox-compatible architecture. For prototype purposes, if real map data is not available, use a high-quality placeholder/vector map component. The map should show: - India boundary - State boundaries - Land-use visualization - Green = forest - Yellow = agriculture - Red/orange = built-up - Blue = water - subtle risk overlays Important: This must look like an actual GIS application, NOT a decorative map image. DESIGN DETAIL ------------- Use: - 16–24px border radius - subtle 1px borders - extremely soft shadows - generous spacing - consistent 8px spacing system - no visual clutter Charts should be minimal and elegant. Do not use unnecessary animations. Use micro-interactions: - hover states - subtle card elevation - map layer transitions - button feedback - sidebar active state - tooltip on charts RESPONSIVE ---------- Desktop: 1440px and 1920px layouts must look excellent. Tablet: Collapse sidebar appropriately. Mobile: Convert sidebar to drawer. Stack KPI cards. Map becomes full-width. Right intelligence cards become vertical. TECHNICAL STRUCTURE -------------------- Use: Frontend: Next.js TypeScript Tailwind CSS Maps: MapLibre GL JS Charts: Recharts or another lightweight chart library. Icons: Lucide React. Architecture should be component-based. Create reusable components such as: DashboardLayout Sidebar TopHeader HeroBanner KPIGrid KPIStatCard IndiaMap MapControls MapLayerPanel IntelligenceCard LandUseChart DisputeChart ClimateRiskCard ImpactNavigationCard IMPORTANT: Do not hardcode the entire UI into one giant component. Create clean reusable components. DATA ---- For now, use clearly separated mock data. Create: /data/dashboard.ts The mock data must be easy to replace with APIs later. Do not fabricate a complicated backend. The dashboard should be visually functional even if real government APIs are not connected. MAP --- Create the map architecture so that later we can connect: - Bhuvan / NRSC - Sentinel/LULC - DILRMP - State land records - climate layers - dispute aggregates - infrastructure - protected areas For now, use safe demo/mock layers. Do not claim that mock data is real government data. ACCESSIBILITY ------------- Ensure: - readable contrast - keyboard navigation - semantic HTML - accessible buttons - tooltips - screen-reader labels FINAL VISUAL TARGET ------------------- The final result should feel like: "India's national land intelligence command center" but NOT like a military dashboard. It should feel closer to a combination of: premium research institute + modern GIS platform + government policy dashboard + Indian land/environment visual identity. The most important thing is CLARITY. A judge should understand the product in 5 seconds: BHUMI-NITI → India's evidence-based land intelligence platform → map + evidence + policy + research Do not build other routes yet. ONLY implement the Dashboard route and the shared layout/navigation needed for it. Keep all other sidebar routes as placeholders for now. Use the attached reference screenshot as visual inspiration.
